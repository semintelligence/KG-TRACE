7. Honest Observations

  • AUROC: SVM (0.9787) > XGBoost (0.9764) > KG-AMR v2 (0.9740) > RF (0.9604). KG-AMR v2 is not the best on raw AUROC.
  • F1-macro: XGBoost (0.9579) ≈ KG-AMR v2 (0.9580) ≈ SVM (0.9576) >> RF (0.8350).
  • BCS@10: KG-AMR v2 = 1.0 — all top-10 SHAP features map to CARD genes (same for XGBoost/RF baselines since all features are named by gene).
  • Fusion Gate: 100% KG-dominated (mean=0.2572). The model relies more on KG embeddings than genomic features.
  • Spearman ρ (Attn vs SHAP): ρ=-0.6855. Negative correlation means attention and saliency rank genes inversely — attention weights do not simply replicate SHAP.
  • Spearman ρ (Attn vs CARD): ρ=-0.2274, p=0.264013. NOT significant — attention does not directly correlate with CARD resistance edge counts.
